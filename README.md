# StaffSync – Modern HR Management System

StaffSync is a MERN-stack Human Resource Management System designed to simplify employee management, attendance tracking, leave requests, and payroll overview.

## Features
- Dashboard with workforce statistics
- Employee management
- Attendance tracking
- Leave request management
- Payroll overview
- Settings and navigation dashboard

## Tech Stack
- **Frontend:** React.js, JavaScript, CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Render
- **Version Control:** Git and GitHub

## Project Structure
- `client/` – React frontend
- `Server/` – Express backend

## Run Locally

### Backend
1. Open a terminal in the `Server` folder.
2. Install dependencies using `npm install`.
3. Configure your MongoDB connection in a `.env` file.
4. Start the backend using `npm start` (or the start command defined in `package.json`).

### Frontend
1. Open a terminal in the `client` folder.
2. Install dependencies using `npm install`.
3. Start the frontend using `npm run dev`.

## Deployment
The frontend and backend are deployed on Render.

## Purpose
This project demonstrates full-stack web development using the MERN stack and CRUD-based employee management.
